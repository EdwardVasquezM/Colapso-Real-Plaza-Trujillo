# Seguridad estructural: Real Plaza Trujillo

Presentación educativa de Edward Vásquez Morales para discutir seguridad estructural, inspección, mantenimiento y propuestas de mejora a partir del caso Real Plaza Trujillo.

**Alcance:** material de reflexión técnica, no un informe pericial ni una determinación verificada de las causas del colapso. La revisión organizativa no valida las conclusiones causales ni las comparaciones normativas del HTML.

## Consultar

- [Presentación publicada](https://EdwardVasquezM.github.io/Colapso-Real-Plaza-Trujillo/).
- Para consulta local, descarga el repositorio completo y abre `index.html`.
- Utiliza **Anterior** y **Siguiente** para recorrer las 12 diapositivas.

La página carga Tailwind CSS y Google Fonts desde Internet.
